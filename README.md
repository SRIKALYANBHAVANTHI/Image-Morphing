# Image Morphing Using Python Techniques

A computer-vision project exploring image morphing and image-processing techniques with Python. The repository includes a Jupyter notebook, sample images, and supporting project documentation.

## Repository contents

- `MORPHING CODE/MorphingCode.ipynb` — notebook containing the image-processing workflow.
- `MORPHING CODE/car.jpg` and `alphabet.jpg` — sample input images.
- `MORPHING CODE.zip` and `MORPHING CODE/` — packaged project materials.
- `Image Morphing Using Python Techniques Documentation.docx` — project documentation.
- `Image Morphing Using Python Techniques.pptx` — project presentation.

## Technologies visible in the notebook

- Python
- OpenCV
- NumPy
- Matplotlib
- scikit-image (SSIM metric)

The notebook currently demonstrates grayscale image loading and Otsu thresholding as part of its image-processing workflow.

## Getting started

1. Clone this repository.
   ```bash
   git clone https://github.com/SRIKALYANBHAVANTHI/Image-Morphing.git
   cd Image-Morphing
   ```
2. Install the notebook dependencies.
   ```bash
   pip install opencv-python numpy matplotlib scikit-image jupyter
   ```
3. Open `MORPHING CODE/MorphingCode.ipynb` in Jupyter Notebook or JupyterLab.

Run the notebook from its project directory so the relative sample-image paths resolve.
